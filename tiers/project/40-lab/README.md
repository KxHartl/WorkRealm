# 40-lab

- `protocols/` — how a test is run, step by step, so it can be repeated.
- `results/RUN-<YYYYMMDD>[-NN]/` — one folder per run. **Write-once**: a re-run is a new folder.
  Each run records what was run, on what version, and the raw output.

Results feed `30-decisions/`; they do not interpret themselves.
